# Simulador Educativo de Emergencias

Proyecto académico desarrollado por SOLUTIONS S.A.S.,
estudiantes de Tecnología en Desarrollo de Software de
la Universidad del Valle - Sede Yumbo.

## Descripción

Aplicación web educativa orientada a apoyar el aprendizaje
de protocolos de emergencia.

El simulador permitirá que los usuarios desarrollen
actividades grupales con escenarios de emergencia,
como sismos e incendios.

## Instalación y ejecución

### 1. Clonar el repositorio

git clone URL_DEL_REPOSITORIO

### 2. Ejecutar el frontend

cd frontend
npm install
npm run dev

El frontend se ejecutará normalmente en:
http://localhost:5173

### 3. Ejecutar el backend

Desde otra terminal, ubicada en la raíz del proyecto:

cd backend
npm install
npm run dev

El backend se ejecutará en:
http://localhost:3000

## API REST

Endpoint de prueba:

GET /api/health

Permite verificar que el backend está funcionando.
